# AGENTS.md

Instructions for any AI agent (including this project's own `ai-agent`) working in this repo.

When working on issues or tasks:

1. Use Python 3.10+ and modern typing.
2. Keep changes minimal and focused; do not refactor unrelated code.
3. Always add or update tests under `tests/` for behavioural changes.
4. Run `pytest -q` and `ruff check .` before opening a PR.
5. Never modify generated files by hand.
6. Open a PR that explains what changed and why, referencing the issue.

This file is read first by the agent and treated as the source of truth.
