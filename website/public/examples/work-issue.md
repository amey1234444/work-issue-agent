# Workflow: Work Issue

1. Read the task and repository instructions.
2. Inspect the relevant implementation and tests.
3. Plan a focused change and select the files to read.
4. Implement the requested behavior and appropriate tests.
5. Run the project's verification command.
6. Summarize changes, test output, and remaining limitations in the PR.

Keep edits focused. Return complete file contents, not patch diffs.
Do not invent verification results.
