# Repository Instructions

This starter targets a Python project. Adapt it to your actual repository.

- Use Python 3.10+ and modern typing.
- Keep edits focused on the requested task.
- Preserve public interfaces unless the task explicitly changes them.
- Add tests for behavior changes and relevant edge cases.
- Run pytest -q and report the actual result.
- Do not modify generated files by hand.
- Do not include secrets or unrelated changes in a proposed commit.
- Explain the change and verification in the pull request.
